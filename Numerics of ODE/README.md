\# Numerics of ODE



This folder contains MATLAB implementations for numerical solutions of Ordinary Differential Equations (ODEs).



The codes include numerical methods for Initial Value Problems (IVPs), systems of differential equations, nonlinear ODEs, and two-point Boundary Value Problems (BVPs).



Implemented methods include:



\- Euler methods (Forward, Backward, Average Euler, Euler-Trapezoidal)

\- Runge-Kutta methods (2nd, 3rd, and 4th order)

\- Taylor series methods

\- Nystrom methods

\- Multistep methods:

&#x20; - Adams-Bashforth

&#x20; - Adams-Moulton

&#x20; - Milne-Simpson

&#x20; - Numerov

&#x20; - Cowell methods

\- Variable mesh techniques

\- Linear and nonlinear BVP solvers
